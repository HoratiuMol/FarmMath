Five barns, five roofs

Five buildings drawn from zero — no shared geometry with the live barn.obj, and no two of these sharing a roof form either. Each is real low-poly geometry (boxes, a cylinder, an extruded arch), flat-shaded and painter’s-algorithm sorted, the same technique the game's renderer uses. Spin the shared dial to compare silhouettes.

These are concept meshes for comparing shape, not drop-in game assets — the live barn is a Wings3D export (barn.obj, 1,657 verts). Whichever silhouette wins would still need a proper pass in Wings3D (or similar) to reach that fidelity before it replaces domain/BarnMesh.kt's asset.
