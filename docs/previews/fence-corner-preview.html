Farm Math Builder · Asset Preview

Fence corner, design options

Four directions for fixing the boundary fence's corner joints — where the current asset's straight one-tile picket run, rotated 90° between the two edges, doesn't form a clean miter and instead reads as overlapping/ disconnected pickets. Each option is shown as a small L-shaped corner section, isometric, on the game's own ground green, at the same tile scale.

Why the current fence.fbx-based mesh can't self-miter: each module is a straight run of pickets built for continuing straight, not turning a corner — rotating it 90° for the perpendicular edge gives two independent, differently-angled meshes that happen to sit near the same post but were never designed to butt against each other cleanly. A code-only fix (drawing both orientations at the shared corner post) has already been tried as the lowest-risk attempt; these four are the fallback if that still doesn't read cleanly on-device.

AFlat 2D picket wall

Drops the 3D mesh entirely — pickets and rail drawn as flat Canvas shapes (same "programmatic 2D" grammar as the wheat/carrot tiles), with one dedicated corner post. Corners trivially work: a post is just a post, wall segments run up to it from either side. Lowest visual detail of the four, but zero corner ambiguity and cheapest to compute.

BContinuous rope + pickets

The whole boundary is one continuous path (not per-cell modules) with picket ticks stamped along its length at even spacing. Corners are automatically seamless because there's only one line being drawn, not two separate rotated pieces meeting — the direction just changes at the path's own corner vertex.

CSolid hedge/wall ribbon

The boundary becomes one filled ring polygon (inner edge + outer edge, offset by wall thickness) instead of individual fence posts — a low stone wall or hedge look. Corners are perfect by construction (they're just the polygon's own vertices), the most robust option here, at the cost of the picket-fence character.

D3D low-poly, dedicated corner post

Keeps today's exact look (same flat-shaded low-poly style as the barn) but adds a genuine hand-built corner module — 4 pickets fanned around a shared post — used only at the 4 map corners, straight runs unchanged elsewhere. Most faithful to the current asset, but the most implementation work (a new procedural corner mesh, not sourced from fence.fbx, since that file has no corner geometry at all).

All four render the ground/tile scale identically to the shipped game (56×30px tile, scaled 2× here for legibility) so proportions compare accurately. These are static corner-only mockups — not full-boundary previews — since the corner joint is the specific thing being evaluated.
