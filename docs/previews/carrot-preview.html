Carrot crop, design options

Four visual directions for the new carrot crop, each shown across its 4 growth phases (Seed → Sprout → Plant → Mature), rendered the same way the shipped wheat tile is — a full-diamond-tile procedural pattern on the game's actual crop-tile ground color, not a centered icon. Pick a letter and I'll build it into the real game the same way drawWheatTile works today.

A

Wheat-style continuation

Selected — building this one

Same visual grammar as the shipped wheat tile (soil furrows, seed dots, scattered blade strokes) — feathery green tops instead of wheat blades. Revised per feedback to carry more orange earlier: a couple of Seed-phase flecks are warm orange instead of plain soil brown, Sprout/Plant now show small orange root-tips breaking the surface as the plant fills in, and Mature has more/larger shoulders each with a short tapering root-tip stroke, so the tile reads unmistakably "carrot" rather than "green tuft with an orange dot." Reuses the exact same helper functions (furrows/seed-dots/scatter-blades) already in FarmGridCanvas.kt, just re-tuned colors/shapes.

B

Chibi bunch

Cute, rounded, thick-outlined carrots — same friendly "chibi sticker" language as the cow's design B. Bright saturated orange against dark outlines reads clearly at small tile size and feels distinctly celebratory at Mature (a little bunch of carrots, not just a texture). Most work to add (new shape vocabulary, not reused wheat helpers) but strongest "kid-appeal" payoff.

C

Flat paper-cutout

Geometric flat-color shapes, soft drop shadow, no outlines — minimal and quick to scan, closest in spirit to a clean mobile-game art style. A calmer, more "designed" look than A, but a visibly different rendering technique (polygons, not scattered strokes) so it'd read as a deliberate style upgrade rather than "the same field, orange version."

D

Pixel art

Small retro pixel sprite per phase (color-grid rendering, no shape math — cheapest to draw). Reads as a distinct "8-bit" language next to the soft-shaded wheat/barn/fence art elsewhere in the game; only worth it if a pixel-art crop line is wanted deliberately rather than as a one-off.

All four sit on the same tile background color the real WHEAT/crop cells already use (0xFFDCEDC8) so scale/contrast reads the same as in-game. This is a static design/scale preview only — the shipped version would keep the existing per-cell deterministic seeding (no reshuffle on tick recomposition) and the Mature phase's subtle light-direction gradient, same as drawWheatTile today.
